1. Apa gunanya IFRAME?

Jawaban: IFRAME (Inline Frames) berfungsi untuk meng-embed (menyisipkan) dokumen lain atau menampilkan konten dari halaman web lain ke dalam halaman web yang sedang aktif, seperti video, peta, profil tokoh, atau media interaktif lainnya.

2. Apa bedanya FRAME dan IFRAME?

Jawaban:

  • FRAME: Digunakan untuk membagi seluruh jendela browser menjadi beberapa bagian terpisah (menggunakan elemen <frameset>). Sifatnya kaku dan sudah tidak didukung di HTML5.
  • IFRAME: Berfungsi sebagai bingkai inline yang dapat disisipkan secara fleksibel di dalam bagian <body> sebuah halaman web biasa tanpa mengganggu struktur layout utama.

3. Tuliskan bentuk umum perintah IFRAME secara lengkap?

Jawaban: Bentuk umum penulisan perintah IFRAME beserta atribut utamanya adalah sebagai berikut:

<iframe src="URL" height="500px" width="100%" frameborder="1" name="nama_iframe">
    <p>Tulisan ini akan tampil jika browser tidak mendukung Iframe</p>
</iframe>

4. Berikan contoh dalam bentuk tampilan website penggunaan IFRAME?

Jawaban: Di bawah ini adalah contoh penerapan <iframe> untuk menyisipkan halaman ensiklopedia Wikipedia mengenai tokoh publik (B. J. Habibie) langsung ke dalam halaman web:

<!DOCTYPE html>
<html>
<head>
    <title>Profil Tokoh Publik - IFRAME</title>
</head>
<body>
    <h2>Profil Tokoh Publik: B. J. Habibie</h2>
    <iframe src="https://id.m.wikipedia.org/wiki/B._J._Habibie" width="100%" height="500px" frameborder="1">
        <p>Browser Anda tidak mendukung iframe.</p>
    </iframe>
</body>
</html>
